BACKEND IOT HISTORICO - SUPABASE + WOKWI

1. Crear proyecto en Supabase.
2. Ejecutar supabase.sql en SQL Editor.
3. Crear entorno virtual: python -m venv venv
4. Activar Windows: venv\Scripts\activate
5. Instalar: pip install -r requirements.txt
6. Copiar .env.example como .env y completar las credenciales.
7. Ejecutar: python app.py
8. Crear ESP32 + DHT22 en Wokwi.
9. Colocar la URL pública de la API en API_URL.
10. Ejecutar la simulación y comprobar registros en Supabase.

NO publiques la clave de Supabase dentro del ESP32.
